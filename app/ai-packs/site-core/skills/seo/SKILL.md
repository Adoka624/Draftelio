# SEO и структура

Для страницы подготовь содержательный title, meta description и lang="ru". Заголовок h1 описывает назначение страницы. Используй смысловые section, header, main и footer. Ссылки имеют понятные подписи. Сохраняй канонический URL, если он задан; не выдумывай домен и не вставляй фиктивную микроразметку рейтингов. Для изменения одного блока не добавляй head или doctype.
