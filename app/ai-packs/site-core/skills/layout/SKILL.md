# Адаптивная вёрстка

Проектируй сначала для узкого экрана 360 px. Для колонок используй grid с auto-fit/minmax и flex-wrap. Не задавай фиксированную ширину шире экрана. Ограничивай ширину основного содержимого и центрируй его. Используй gap для промежутков, а не цепочки случайных margin. Подбирай размеры заголовков через clamp. Сохраняй порядок секций и якоря. Проверяй длинные слова, изображения max-width:100%, паддинги и переполнение. Координаты разрешены только в явном свободном холсте.
