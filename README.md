# Draftelio

**Создавайте сайты визуально — на русском языке, прямо на своём компьютере.**

Draftelio — бесплатный настольный редактор сайтов для Windows с открытым исходным кодом. Меняйте текст прямо на странице, собирайте собственные блоки в мастерской или поручайте создание сайта ИИ. Сохранённый сайт — обычные HTML, CSS и ресурсы, которые можно разместить на выбранном вами хостинге.

Интерфейс «Орбита» объединяет компактную панель инструментов, раскрывающиеся меню и светлую/тёмную темы.

[Скачать для Windows](https://github.com/Adoka624/Draftelio/releases/latest) · [Сообщить об ошибке](https://github.com/Adoka624/Draftelio/issues)

## Для кого

Для тех, кто хочет самостоятельно собрать лендинг, сайт компании, портфолио или небольшой информационный сайт. Основные визуальные правки можно делать без ручного редактирования HTML и кодов цветов. Для более сложных задач доступен редактор кода.

## Возможности

- Главная страница с проектами: создать, открыть, найти и переключить сайт.
- Редактирование текста, ссылок и фотографий прямо на странице.
- Перетаскивание блоков, свободное размещение, размеры и координаты, контекстное меню.
- Мастерская собственных блоков с палитрой цветов, слоями и адаптивными макетами.
- Отмена и повтор действий, резервные копии страниц, экспорт HTML/CSS/ресурсов.
- ИИ для создания сайтов: ChatGPT через официальный Codex CLI, Claude через Claude Code CLI; инструкции, навыки и пакеты блоков. Изменения появляются в редакторе и допускают отмену.

## Как устроена работа

1. Создайте проект или откройте папку существующего HTML-сайта.
2. В режиме **«Текст»** нажмите на надпись и измените её прямо на странице.
3. В режиме **«Блоки»** перемещайте элементы, задавайте размеры и расположение, заменяйте фотографии.
4. Создавайте повторно используемые компоненты в **мастерской** или отправляйте задачу в панель **«ИИ»**.
5. Проверьте вид для телефона, планшета и компьютера, сохраните или экспортируйте сайт.

Неудачную правку можно отменить. При сохранении страницы программа создаёт резервную копию предыдущей версии.

## Windows

Скачайте ZIP из Releases, распакуйте всю папку и запустите `Draftelio.exe`. Программа работает локально, установка не нужна. Подпись Windows пока отсутствует.

Проекты по умолчанию находятся в `Документы/Codex/Draftelio-Sites`, настройки — в `Документы/Codex/Draftelio-data`. Старые папки переносятся автоматически при обновлении. Внешние проекты остаются на своих местах.

## Запуск из исходников

Нужны Node.js 24 и Windows x64:

```powershell
cd app
npm ci
npm test
npm start
```

Сборка переносимой версии из корня репозитория:

```powershell
node build.js app/node_modules/electron/dist
```

Она появится в `Windows/`. Сборка использует официальный Electron 44.5.1.

## Проверка интерфейса

После сборки установите Playwright и выполните проверки в отдельных временных профилях:

```powershell
npm ci
npm run test:ui
```

Локальные проверки сохранения, изображений, экспорта, защиты путей и ИИ включены в `npm test` внутри `app`. Проверки ИИ используют искусственные ответы: они не подтверждают доступность подписки или провайдера. Claude и реальная авторизация проверяются отдельно с вашим аккаунтом.

## Подключение ИИ

Установите официальный Codex CLI или Claude Code CLI, затем подключитесь через панель «ИИ». Нужна подписка с доступом к соответствующему инструменту провайдера. Программа не предоставляет собственную подписку; лимиты устанавливает провайдер. API-ключи для этого режима не требуются. Подробнее: [инструкции ИИ](app/AI-INSTRUCTIONS.md).

## Данные и ограничения

Проекты и настройки хранятся локально. При использовании ИИ задача и HTML выбранной области передаются выбранному провайдеру. Личные сайты, настройки и данные авторизации не входят в опубликованные исходники или архив программы.

Draftelio редактирует HTML-сайты. Серверная часть, базы данных, приём платежей и полноценная авторизация посетителей требуют отдельной разработки и настройки. Предпросмотр размеров устройств помогает проверить макет, но адаптивность зависит от структуры и стилей сайта.
